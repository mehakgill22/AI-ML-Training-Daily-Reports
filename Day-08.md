# Day 8 – Data Preprocessing: Encoding, Normalization and Feature Scaling

## Topics Covered
- Introduction to Data Preprocessing.
- Understanding categorical and numerical data.
- Encoding categorical variables.
- Introduction to Normalization.
- Feature Scaling techniques.
- Importance of preprocessing in Machine Learning.

## Work Performed

Today's session focused on data preprocessing and its importance in preparing datasets for Machine Learning. We discussed how raw data often needs to be converted into a suitable format before it can be used for training a model.

We learned about encoding, which is used to convert categorical data into numerical values so that Machine Learning algorithms can process it. We also discussed normalization and how it helps bring numerical values into a common range.

The session further covered feature scaling and its importance when different features have different value ranges. We discussed how these techniques help maintain consistency in datasets and improve the overall model training process.

## Learning Outcomes

- Understood the purpose of data preprocessing.
- Learned why categorical data needs encoding.
- Became familiar with normalization techniques.
- Understood the importance of feature scaling.
- Learned how preprocessing prepares data for Machine Learning algorithms.

## Conclusion

The session provided an understanding of different data preprocessing techniques and how they help transform raw datasets into a suitable format for Machine Learning.
