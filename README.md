# Artificial Intelligence and Machine Learning Training

## About the Training
This repository contains my daily learning reports from a 4-week Artificial Intelligence and Machine Learning training program. The training provided an introduction to AI, ML and Deep Learning concepts, along with different algorithms, data preprocessing techniques and real-world applications.

## Training Objectives
- Understand the fundamentals of Artificial Intelligence and Machine Learning.
- Learn Python libraries used in machine learning.
- Understand data collection, cleaning and preprocessing.
- Explore different machine learning algorithms.
- Learn model evaluation and validation techniques.
- Get familiar with neural networks, computer vision and NLP.
- Understand the basics of model deployment.

## Topics Covered

1. Introduction to AI, ML and Deep Learning
2. Types of Machine Learning
3. Real-World Applications of AI/ML
4. Machine Learning Workflow
5. Python Fundamentals – NumPy and Pandas
6. Data Collection and Dataset Understanding
7. Data Cleaning
8. Data Preprocessing
9. Exploratory Data Analysis (EDA)
10. Basic Statistics, Probability and Linear Algebra
11. Regression Algorithms
12. Classification Algorithms
13. Model Evaluation Metrics
14. Clustering Techniques
15. Dimensionality Reduction using PCA
16. Neural Networks and Deep Learning
17. Computer Vision
18. Natural Language Processing (NLP)
19. Model Deployment and Final Project Presentation
