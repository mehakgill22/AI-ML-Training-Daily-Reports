# Day 21 – Hierarchical Clustering and PCA

## Topics Covered
Today’s session focused on Hierarchical Clustering and Principal Component Analysis (PCA). We learned how hierarchical clustering creates groups of similar data points in a tree-like structure. We also explored PCA, a dimensionality reduction technique used to simplify datasets while preserving important information.

## Work Performed
- Studied the basic concept of Hierarchical Clustering.
- Learned about the two approaches: Agglomerative and Divisive Clustering.
- Understood how clusters are formed by combining or dividing data points.
- Explored the concept of a Dendrogram and how it helps visualize hierarchical relationships.
- Studied Principal Component Analysis (PCA) and its importance in reducing the number of features in a dataset.
- Understood how PCA transforms data into principal components while retaining as much important information as possible.
- Discussed how dimensionality reduction can make data analysis simpler and more efficient.

## Learning Outcomes
- Understood the working of Hierarchical Clustering.
- Learned the difference between Agglomerative and Divisive approaches.
- Understood the role of Dendrograms in clustering.
- Learned how PCA helps reduce dataset dimensions.
- Identified the importance of dimensionality reduction in machine learning.

## Conclusion
Today’s session helped me understand two important techniques used in machine learning. I learned how Hierarchical Clustering organizes similar data points and how PCA reduces the complexity of datasets while preserving useful information.
