# Day 13 – Introduction to Regression

## Topics Covered
- Introduction to Regression in Machine Learning.
- Understanding Regression Problems.
- Difference between Regression and Classification.
- Dependent and Independent Variables.
- Types of Regression.
- Real-world applications of Regression.

## Work Performed

Today's session introduced the concept of Regression in Machine Learning. We discussed how regression is used to predict continuous numerical values based on the relationship between different variables.

We learned about dependent and independent variables and how they are used in a regression problem. The difference between regression and classification was also discussed, with examples to understand when each approach is used.

The session included an overview of different regression techniques and their applications in real-life situations, such as predicting house prices, sales and other numerical values.

## Learning Outcomes

- Understood the basic concept of Regression.
- Learned how regression is used for numerical predictions.
- Understood dependent and independent variables.
- Learned the difference between Regression and Classification.
- Became familiar with practical applications of regression.

## Conclusion

The session provided a basic understanding of regression and its role in Machine Learning. It also prepared the foundation for learning Linear Regression in the next session.
