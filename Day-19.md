# Day 19 – Model Evaluation Metrics and Validation

## Topics Covered
Today’s session focused on evaluating the performance of machine learning models. We learned about different evaluation metrics, including Accuracy, Precision, Recall and F1 Score. We also studied the Confusion Matrix and basic model validation techniques.

## Work Performed
- Understood why evaluating a machine learning model is important.
- Studied Accuracy to measure the overall correctness of predictions.
- Learned about Precision and Recall and how they help evaluate classification models.
- Understood the F1 Score as a combination of Precision and Recall.
- Studied the Confusion Matrix and its four components: True Positive, True Negative, False Positive and False Negative.
- Explored model validation techniques, including the train-test split and cross-validation.
- Discussed how these techniques help identify whether a model performs well on unseen data.

## Learning Outcomes
- Understood the importance of model evaluation.
- Learned the difference between Accuracy, Precision, Recall and F1 Score.
- Understood how to interpret a Confusion Matrix.
- Learned how train-test split and cross-validation help check model performance.

## Conclusion
Today’s session helped me understand how machine learning models are evaluated. I learned that selecting the right evaluation metric and using proper validation techniques are important for checking the reliability and performance of a model.
