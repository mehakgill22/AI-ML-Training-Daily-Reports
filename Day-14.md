# Day 14 – Linear Regression

## Topics Covered
- Introduction to Linear Regression.
- Understanding Simple Linear Regression.
- Dependent and Independent Variables.
- Linear Relationship between Variables.
- Best Fit Line.
- Applications of Linear Regression.

## Work Performed

Today's session focused on Linear Regression, one of the basic algorithms used in Supervised Machine Learning. We discussed how it is used to predict continuous numerical values by identifying the relationship between input and output variables.

We learned about the concept of a best fit line and how it represents the relationship between two variables. The session also covered how a model uses existing data to understand patterns and make predictions for new inputs.

Simple examples, such as predicting house prices based on their area and estimating sales based on previous data, were discussed to understand the working of Linear Regression.

## Learning Outcomes

- Understood the working of Linear Regression.
- Learned about dependent and independent variables.
- Understood the concept of a best fit line.
- Learned how Linear Regression makes numerical predictions.
- Became familiar with its real-world applications.

## Conclusion

The session provided an understanding of Linear Regression and its use in predicting continuous values. It also helped in understanding how relationships between variables can be used to build predictive Machine Learning models.
