# Day 7 – Data Cleaning Techniques: Handling Missing Values and Outliers

## Topics Covered
- Introduction to Data Cleaning.
- Importance of clean data in Machine Learning.
- Understanding missing values in datasets.
- Different methods of handling missing values.
- Introduction to outliers.
- Methods for identifying and handling outliers.

## Work Performed

Today's session focused on data cleaning and why it is an important step before building a Machine Learning model. We discussed how real-world datasets may contain missing values, incorrect entries and unusual observations that can affect the results.

We learned about different ways of handling missing values, including removing incomplete records and filling missing entries using suitable values such as mean, median or mode.

The session also introduced outliers and how they can affect data analysis and model performance. We discussed basic methods of identifying unusual values and the importance of treating them carefully instead of removing them without proper understanding.

## Learning Outcomes

- Understood the importance of data cleaning.
- Learned different methods for handling missing values.
- Became familiar with the concept of outliers.
- Understood how unusual values can affect datasets.
- Learned why clean and consistent data is important for Machine Learning.

## Conclusion

The session helped in understanding common problems found in real-world datasets and the techniques used to improve data quality before applying Machine Learning algorithms.
