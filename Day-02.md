# Day 2 – Types of Machine Learning

## Topics Covered
- Introduction to different types of Machine Learning.
- Supervised Learning.
- Unsupervised Learning.
- Reinforcement Learning.
- Differences between the three learning approaches.
- Examples of Machine Learning in real-world applications.

## Work Performed

Today, we learned about the three major types of Machine Learning: Supervised Learning, Unsupervised Learning and Reinforcement Learning.

The session started with Supervised Learning, where we discussed how a model learns from labelled data and uses it to make predictions. We also learned about Unsupervised Learning, which works with unlabelled data to identify hidden patterns and groups.

After that, Reinforcement Learning was introduced. We discussed how an agent learns by interacting with its environment and receiving rewards or penalties based on its actions.

Different examples were discussed to understand how these learning methods are used in practical applications.

## Learning Outcomes

- Understood the three main types of Machine Learning.
- Learned the difference between labelled and unlabelled data.
- Understood the basic working of reward-based learning.
- Became familiar with the applications of different ML approaches.

## Conclusion

The session helped in understanding the different approaches used in Machine Learning and how each approach is suitable for different types of problems.
