# Day 15 – Logistic Regression for Classification

## Topics Covered
- Introduction to Logistic Regression.
- Understanding Classification Problems.
- Difference between Regression and Classification.
- Binary Classification.
- Sigmoid Function.
- Applications of Logistic Regression.

## Work Performed

Today's session focused on Logistic Regression, a Supervised Machine Learning algorithm mainly used for classification problems. We discussed how it helps predict the category or class to which a particular data point belongs.

We learned about binary classification, where the output is divided into two possible categories, such as Yes or No. The session also introduced the Sigmoid Function, which converts model outputs into probability values between 0 and 1.

We discussed how Logistic Regression can be used in practical situations such as spam email detection, predicting customer responses and identifying whether a transaction is fraudulent or not.

## Learning Outcomes

- Understood the basic working of Logistic Regression.
- Learned the concept of classification.
- Became familiar with binary classification.
- Understood the purpose of the Sigmoid Function.
- Explored real-world applications of Logistic Regression.

## Conclusion

The session helped in understanding how Logistic Regression is used to solve classification problems and predict categories based on input data. It also introduced the role of probability in classification models.
