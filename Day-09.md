# Day 9 – Exploratory Data Analysis (EDA)

## Topics Covered
- Introduction to Exploratory Data Analysis.
- Importance of data exploration.
- Understanding dataset structure.
- Identifying patterns and trends in data.
- Use of summary statistics.
- Data visualization using graphs and charts.

## Work Performed

Today's session focused on Exploratory Data Analysis (EDA), which is an important step in understanding a dataset before applying Machine Learning algorithms.

We discussed how to examine a dataset to understand its structure, identify different features and find patterns or unusual values. We also learned about basic statistical summaries that help in understanding the distribution of data.

The session introduced different types of visualizations, such as bar charts, histograms and scatter plots. We discussed how graphs make it easier to identify relationships between variables and understand the overall behaviour of data.

## Learning Outcomes

- Understood the purpose and importance of EDA.
- Learned how to examine the structure of a dataset.
- Became familiar with summary statistics.
- Understood how graphs and charts help in data analysis.
- Learned how to identify basic patterns and trends in data.

## Conclusion

The session helped in understanding how Exploratory Data Analysis is used to study and interpret datasets. It also highlighted the importance of data visualization before developing Machine Learning models.
