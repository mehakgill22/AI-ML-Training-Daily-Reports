# Day 17 – Decision Trees

## Topics Covered
- Introduction to Decision Trees.
- Structure of a Decision Tree.
- Root Nodes, Decision Nodes and Leaf Nodes.
- Splitting of Data.
- Gini Index and Entropy.
- Applications of Decision Trees.

## Work Performed

Today's session focused on Decision Trees, a Supervised Machine Learning algorithm used for both classification and regression problems.

We learned how a Decision Tree makes predictions by dividing data into smaller groups based on different conditions. The structure of a tree was explained through its root node, decision nodes and leaf nodes.

We also discussed how the algorithm selects the best feature for splitting the data. Basic concepts of Gini Index and Entropy were introduced to understand how the quality of a split is measured.

Examples were discussed to understand how Decision Trees can be used for tasks such as predicting customer decisions and classifying data into different categories.

## Learning Outcomes

- Understood the basic working of Decision Trees.
- Learned about different nodes in a decision tree.
- Understood how data is divided using conditions.
- Became familiar with Gini Index and Entropy.
- Explored practical applications of Decision Trees.

## Conclusion

The session helped in understanding how Decision Trees use a tree-like structure to make predictions. It also introduced the basic techniques used to select features and divide data during model building.
