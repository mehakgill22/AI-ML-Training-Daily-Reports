# Day 6 – Data Collection Methods and Dataset Understanding

## Topics Covered
- Introduction to Data Collection in Machine Learning.
- Different methods of collecting data.
- Understanding datasets and their structure.
- Introduction to rows, columns and features.
- Understanding input and target variables.
- Importance of data quality in Machine Learning.

## Work Performed

Today's session focused on data collection and understanding datasets before using them in Machine Learning. We discussed different ways of collecting data, such as surveys, online sources, databases and existing datasets.

We also learned how a dataset is organised in tabular form, where rows represent individual records and columns contain different attributes. The concepts of features and target variables were explained with simple examples.

We discussed why it is important to understand the dataset before applying any Machine Learning algorithm. The importance of checking data quality, identifying relevant information and understanding the available attributes was also covered.

## Learning Outcomes

- Understood different methods of collecting data.
- Learned the basic structure of a dataset.
- Became familiar with rows, columns and features.
- Understood the difference between input features and target variables.
- Learned why dataset understanding is important before model development.

## Conclusion

The session helped in understanding how data is collected and organised for Machine Learning projects. It also highlighted the importance of studying a dataset before using it for further processing and model training.
