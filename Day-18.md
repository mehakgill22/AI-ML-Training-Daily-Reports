# Day 18 – Random Forest Algorithm

## Topics Covered
Today’s session focused on the Random Forest Algorithm, a supervised machine learning technique used for both classification and regression tasks. We learned that Random Forest is an ensemble learning method that combines multiple decision trees to produce more accurate and reliable predictions.

## Work Performed
- Studied the basic concept and working of the Random Forest Algorithm.
- Understood how multiple decision trees work together to make a final prediction.
- Learned that Random Forest uses different samples of data and features to build individual trees.
- Explored how predictions are made through majority voting in classification and averaging in regression.
- Discussed the advantages of Random Forest, such as better accuracy and reduced overfitting compared to a single decision tree.
- Understood some common applications, including fraud detection, medical diagnosis and customer prediction.

## Learning Outcomes
- Understood the concept of ensemble learning.
- Learned how Random Forest combines multiple decision trees.
- Identified the difference between a single Decision Tree and Random Forest.
- Understood why Random Forest is useful for making stable and reliable predictions.

## Conclusion
Today’s session helped me understand the working and importance of the Random Forest Algorithm. I learned how combining multiple decision trees can improve prediction performance and reduce the chances of overfitting.
