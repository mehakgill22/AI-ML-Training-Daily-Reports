# Day 10 – Basic Statistics for Machine Learning

## Topics Covered
- Introduction to Statistics.
- Understanding Mean, Median and Mode.
- Concept of Variance.
- Understanding Standard Deviation.
- Importance of statistics in Machine Learning.
- Use of statistical measures to understand datasets.

## Work Performed

Today's session focused on basic statistical concepts that are commonly used in Data Analysis and Machine Learning. We discussed how statistics helps in understanding and summarizing data before using it in a model.

We learned about Mean, Median and Mode and how these measures are used to represent the central value of a dataset. Simple numerical examples were discussed to understand how each measure is calculated and how they differ from one another.

The session also covered Variance and Standard Deviation. We learned how these measures help in understanding the spread and variation of data values. Their importance in analysing datasets and understanding data distribution was also discussed.

## Learning Outcomes

- Understood the basic concepts of statistics.
- Learned the difference between Mean, Median and Mode.
- Understood how Variance measures data spread.
- Became familiar with Standard Deviation.
- Learned the importance of statistical measures in data analysis.

## Conclusion

The session provided a basic understanding of statistical measures used in Machine Learning. These concepts are useful for analysing datasets, understanding data distribution and preparing data for further processing.
